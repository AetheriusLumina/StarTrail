# 星迹 · StarTrail 安装与使用

适用于 0.4.0，Windows 10/11 x64。安装包自带本地翻译环境，不用安装 Python；建议预留至少 1GB 空间。通过默认浏览器打开，个人数据保存在安装目录的 `UserData`。

## 安装、升级与退出

从本项目 Releases 获取 `StarTrail_Setup.exe`，双击安装，从桌面 StarTrail 快捷方式打开。首次获取项目需要网络。旧 GitHub Radar 用户安装到原位置即可保留关键词、历史、关注和设置；升级前不要删除 `UserData`。默认文件夹和内部程序名仍保留旧名，以兼容已有数据。

点侧栏“退出”会结束后台；更新正在运行时先等待更新结束。浏览器不允许自动关闭时，手动关闭该标签页。只关闭标签页不会结束后台。

## 常用操作

| 入口 | 怎么用 |
|---|---|
| 首页 | 右上添加关键词；横线上的 Star 增长和关键词切换已保存项目，竖三点显示全部选项。切换不会自动爬取或调用 AI。 |
| 项目 | 点击 Card 查看详情；六框展示原用途和已保存理解。查看仓库、更新 README、关注在标题右侧；生成理解和模型选择在左侧栏。 |
| 历史 | 右上按名称、日期、来源搜索，或选择日历日期进入当天项目；返回日历回到月历。 |
| 我的关注 | 新建文件夹；点名字切换，点竖三点改名或删除。自建分类可拖动排序，未分类项目可拖入文件夹；全部关注可搜索。删除文件夹保留关注。 |
| 设置 | 检查 Codex 连接、设置关键词门槛/每日更新时间/字号/动效；侧栏切换中文、英文及原文、译文。 |

增长榜使用最近已结束的完整 **UTC** 统计日，北京时间当天 08:00 才结束昨天 UTC 日。历史重复前五紧凑显示，另补最多五个新项目。关键词按当前真实总 Star 优先并历史排重，不机械轮换下一段名次。榜单只覆盖已发现项目，不能保证全站无遗漏。

## 翻译与 AI

入选项目后台分批本地预译，译文存硬盘；重复开关详情不会重新翻译，内容或翻译版本改变才补译。旧历史首次打开可能需要准备译文。翻译免费、不使用 AI token；机器翻译可能生硬，代码和链接保留，可对照原文。

AI 理解仅在你点击后生成，需要另外安装并登录 Codex，使用你自己的账号额度。设置里“检查连接”不生成内容。格式错误可手动重试；不会自动调用 AI 重试。普通浏览、历史搜索和关注不调用 AI。

## 更新和常见问题

- 点“立即更新”优先执行，不需要等待每日定时任务；连续点击复用同一任务。刷新速度受网络、GitHub 请求额度和候选数量影响。
- 更新失败先看左侧状态，检查网络；旧 GitHub 登录失效时，在设置重新登录一次。无需给任何人提供 Token 或 Client Secret。
- 可选登录 GitHub 能提高请求额度；不登录也可查看公开项目，但额度较低。来源尚未发布昨天数据时会保留可核实结果并注明实际统计日。
- 本地翻译提示缺少运行库时，安装微软官方 Visual C++ 2015–2022 x64 运行库后再试。
- 卸载时可以选择保留个人数据；确认删除会永久移除该安装目录的 `UserData`，请先备份。

软件当前为未签名预览版，第二台电脑/干净 Windows 兼容性仍需进一步验证。只从本项目发布页获取安装包；遇到问题请在 Issues 描述步骤，不上传个人数据库、凭证或未脱敏日志。
