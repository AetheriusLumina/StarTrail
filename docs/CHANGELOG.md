# 开发与版本变更日志

## 0.5.0 / v0.5.0-preview.1 — 2026-10-04（已构建验收，待公开发布）

1. 自动更新加入 AI 扩词和实际联网搜索，与 GitHub/Trending/Trendshift 合并，再官方解析和分批判断。新增持久化前沿、内容/证据缓存、每日预算与短事务租约；手动继续和缺口补搜均有界。
2. 修复当天推荐/快照和高 Star 候选替换逻辑；保持历史展示排重，模型/配置/日期变化阻止旧任务发布。用途第一行高亮 schema v3 双语类型，旧缓存不自动付费刷新。
3. 所有详情入口增加多文件夹归类/创建并归类；未分类和自建文件夹可拖动，全部关注禁止，移除卡片移动按钮。
4. 软件更新读取固定 Releases，匿名六小时检查；顶部十秒可关闭提醒，确认后流式校验下载，启动前复验。安装器备份完整 UserData 后更新程序，失败停止覆盖；快捷方式使用软件 ICO。
5. 中英文 README 按当前功能重组，英文改用四张英文实机图；同步手册、开发指南和 AI 对接。仓库 About 添加 18 个相关主题。
6. 完整回归 `python -m unittest discover -s tests`：556 项通过，62.858 秒；Node 更新交互已加入同一 CI 回归。独立复核的换行校验、取消发布、补搜断点、公共来源兜底、重复出处、空结果、空归类和陈旧代次写进度均补回归修复。真实 AI 严格三次均通过：扩词、主动搜索（五次实际搜索事件）、双语技能类型解释。
7. 全公开文件检查零标记，暂存差异检查通过。新安装包 0.5.0 构建成功；冻结资源、双向离线翻译、本机鉴权接口、正常退出通过。隔离安装/覆盖升级保留关键词、历史、关注/分类、设置和测试账号文件，完整备份成功；注入目录联接时停止覆盖，桌面图标正确。验收仅改变安装测试身份，正式数据未触碰。第二台干净 Windows、跨夜长期运行及满预算二百候选真实调用未做；后者为控制额度，不能冒充已验收。公开发布随后记录实际标签与提交。


这里集中记录每次可交付更新，不另建分散的版本报告。当前运行版本、接口边界和后续接续见 [AI 开发接续文档](AI_HANDOFF.md)，维护方法见 [开发指南](DEVELOPMENT.md)。

## 0.4.0 · Windows 预览版

1. 产品从 GitHub Radar 更名为星迹 · StarTrail；显示名称与图标更新，内部包名、安装身份与旧用户数据入口保持兼容。
2. 首次公开安全源码，使用 MIT 许可证；第三方模型、字体与资源分别保留许可说明。
3. 增加独立开发与打包环境、公开文件检查、Windows 回归及手动构建发布工作流。普通提交和 PR 不自动发布安装包。
4. 提供中文 README、独立英文 README、四张实际界面图片、用户手册、开发指南和第三方资源说明。
5. 已发布安装包见 [v0.4.0-preview.1](https://github.com/AetheriusLumina/StarTrail/releases/tag/v0.4.0-preview.1)。源码文档后续更新不代表安装包已重新构建。
6. 边界：Windows 预览包未签名；第二台干净 Windows、真实授权跨夜续期和完整产品长期内存负载仍需进一步实测。既有本机回归及 CI 记录不代替这些检查。

## 以后每次更新的记录格式

同一天可以在“未发布”下添加多项完整记录；正式发布时将对应变化归入实际标签，保留日期和限制。

1. 日期、实际版本/标签或“未发布”。
2. 问题或需求，修改后的具体行为。
3. 受影响模块、API、数据库或安装兼容性。
4. 验证命令、结果、手动验收范围和未覆盖事项。
5. 遗留问题、下一步和回退方法；没有运行的检查明确标记未运行。
