## 以后每次更新的记录格式

同一天可以在“未发布”下添加多项完整记录；正式发布时将对应变化归入实际标签，保留日期和限制。

1. 日期、实际版本/标签或“未发布”。
2. 问题或需求，修改后的具体行为。
3. 受影响模块、API、数据库或安装兼容性。
4. 验证命令、结果、手动验收范围和未覆盖事项。
5. 遗留问题、下一步和回退方法；没有运行的检查明确标记未运行。
